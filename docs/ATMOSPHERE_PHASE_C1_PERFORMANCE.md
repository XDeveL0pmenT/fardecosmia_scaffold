# Atmospheric performance — Phase C1

Локальная development machine, SQLite, Python 3.13, сетка 180×90,
`step_minutes=360`. Каждый запуск `scripts/benchmark_atmosphere.py` выполнен в
отдельном процессе и полностью откачен транзакцией. Значения являются
ориентиром этой машины, а не production SLA.

постоянной: macro-период не симулируется, выполняются только 28 шагов spin-up.

Годовой latitude reference инсоляции строится один раз на конфигурацию
широт/наклона и кешируется. На каждом timestep Kepler state рассчитывается один
раз, а local zenith, stellar flux и Ympha proxy — NumPy-массивами без Python
object на ячейку.

## Long-run reduced-grid stability

`scripts/benchmark_orbital_year.py` выполнил 1456 последовательных шагов на
сетке 24×12 за 0.879 s:

- NaN/Inf: нет;
- температура: 11.429…26.721 °C;
- изменение средней температуры за контролируемый год: −0.0706 °C;
- ошибка повторения stellar surface target через 364 дня: 0.0 °C;
- ошибка повторения расстояния годовой орбиты: 0.0 AU.

Ympha намеренно исключена только из проверки *точного годового повтора target*:
её физический период 7.05 суток не обязан целое число раз укладываться в 364
дня. В полном долгом прогоне её forcing оставался включён.
