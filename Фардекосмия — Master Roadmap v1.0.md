# 0. Базовые архитектурные принципы

- [ ] Разделять три уровня данных: **Canon → Campaign Override → Character Knowledge / State**.
- [ ] Глобальный канон не должен изменяться обычным мастером кампании.
- [ ] Мастер изменяет мир только в своей кампании через overrides.
- [ ] Персонаж видит только известную ему часть мира.
- [ ] Физика мира не должна зависеть от UI.
- [ ] География хранится в реальных `latitude/longitude`, а не только в пикселях карты.
- [ ] Игровое время `world_minutes` остаётся единым source of truth.
- [ ] Важные изменения должны быть пригодны для общего `AuditLog`.
- [ ] Подтверждения покупок, путешествий и других действий должны позже идти через общий `ApprovalRequest`.
- [ ] Глобальные и локальные изменения мира должны объединяться через `WorldEvent`.
- [ ] Генераторы мастера создают черновики, а не автоматически изменяют кампанию.
- [ ] Roll20 используется через adapter, а не как единственный source of truth персонажа.
